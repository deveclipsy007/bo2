## Regras de aplicação

- Não aplicar texto dentro do arquivo-fonte; compor copy por cima em layout com área de respiro.
- Manter preto, branco, prata e transparências; não introduzir cor de acento.
- Usar como sistema, não como decoração aleatória: cada imagem deve corresponder ao conceito que está sendo comunicado.
- Não usar para prometer automação total, liberdade instantânea ou resultado não comprovado.
- Não misturar com assets, símbolos ou elementos proprietários da LBA.
