# Briefing — Operon · "5 motivos para criar seu sistema proprietário inteligente"

Seguindo o Operon Motion System v3.3 (gramática C "hook gravado" + A "Operon/interface" + D "Fluffy"; referência de padrão: *O que é a Operon*).

| Campo | Definição |
|---|---|
| Tema | Por que construir um sistema próprio (proprietário) com inteligência, em vez de só pagar acesso a ferramentas |
| Público | Donos e gestores de empresas que operam com ferramentas de prateleira e dependem de si em cada etapa |
| Objetivo | Fazer o espectador concluir que um sistema próprio é um **ativo** e uma **vantagem**, e que a Operon entrega isso |
| Canal / formato | Reels · 1080×1920 · 60 fps |
| Duração | ≈ 72 s (hook 5,4 s + 7 notas de voz) |
| Narração | Exata, já gravada: hook (vídeo) + 7 notas de voz — ordem definida por transcrição (ver `timeline.json` / `src/films/cinco/data.ts`) |
| Afirmações | Só as falas. Nenhum número, métrica ou resultado inventado; interface genérica ("Etapa 1/2/3", "Ferramenta") |
| Ativos reais | Vídeo do fundador (hook), logo oficial raster (`assets/brand/operon-logo-alpha.png`), Fluffy pelo rig SVG |
| Paleta | Preto `#0b0b0c` ↔ papel `#f5f4f0` ↔ azul `#3d5afe` por trecho; âmbar `#ff9a3c` só para problema/limite; sem vermelho |
| Tipografia | Manrope 650 (títulos, −0,045 em) · DM Sans (apoio) · serifa itálica na palavra de ênfase (Gelasio, clone métrico da Georgia) |
| CTA | Nenhum falado — o filme fecha na assinatura "Operon, tecnologia própria, inteligência conectada, você no comando." |
